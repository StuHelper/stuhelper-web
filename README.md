# StuHelper Web

<!-- updated: 2026-11-21 -->

StuHelper 的学生端 Web 应用，基于 Vue 3、TypeScript、Vite、Vue Router 和 Reka UI 构建。页面覆盖校园目录、评价、学习资料、校园认证、存储贡献和个人中心。服务端判断资格和授权，并提供选课事实。

## 本地开发

需要 Node.js 24.22.1 和 pnpm 10.33.4。

```bash
make setup
make check
make dev
```

开发服务器默认监听 `127.0.0.1:5173`，并将 `/api` 代理到 `127.0.0.1:8080`（可通过 `STUHELPER_API_TARGET` 覆盖）。生产环境由同源反向代理托管静态资源并转发 `/api` 请求。

镜像内的 Nginx 按接口设置传输限制。资料内容上传支持流式转发，单文件上限 1 GiB。上游读取空闲超时按接口设置，资料上传和下载为 300 秒，认证照片为 75 秒，云盘托管为 90 秒。认证照片请求体上限为 1 MiB。

资料上传按 1 MiB 分块计算 SHA-256，传输总时限为 30 分钟。资料及分包下载逐块核对体积后生成 Blob，每次收到内容都重新计算 30 分钟空闲时限。认证照片上传的总时限为 90 秒，托管写入为 105 秒。

## 界面与交互

全局设计令牌位于 `src/styles`，门户与产品介绍样式位于 `src/styles/landing.css`。导航栏、底部标签栏、菜单、弹层与通知使用半透明液态玻璃令牌，正文卡片使用实色表面以确保对比度。

顶部主导航在校园、API 和 Store 之间切换，每个产品区域通过 `data-product` 切换强调色。进入校园区域后显示发现、课程、教师、学习资料与对比二级导航；手机端使用底部悬浮胶囊标签栏。

`AppSelect.vue` 封装 Reka UI 下拉框。总选项超过 11 项时，打开即聚焦搜索框，按选项文字过滤，忽略大小写和空白。资料编辑器的课程和教师选择器显示搜索提示，输入后向服务端查询候选项。校园认证页的下拉框开关保持页面布局稳定。

弹层与快速查看抽屉在手机端从底部滑出。`SheetDialog.vue` 在关闭动画期间保留关闭前的内容，此时内容不可交互。弹窗和抽屉提供有可访问名称的关闭按钮，关闭后将焦点还给仍在页面上的打开控件。确认对话框内显示提交失败和重试操作，表单错误与对应输入框关联。

外观默认跟随系统。样式表通过 `light-dark()` 成对定义浅色、深色令牌，由 `color-scheme` 选择对应值。导航栏可以选择浅色、深色或重新跟随系统。指定外观时，应用将偏好存入 `stuhelper.theme` 并更新根元素的 `data-theme`。全站使用 CSS 逻辑属性适配阿拉伯语从右向左（RTL）布局，并响应系统减弱动态效果设置。

## 服务范围与内容准入

社区默认学校由会话接口 `session.content_school_id` 指定，不使用构建期学校常量。学生与教师认证支持按学校代码、五位代码、名称或登记别名查询学校。

路由通过 `meta.access: 'verified'` 标记校园内容页，通过 `meta.access: 'member'` 标记仅需登录的个人记录页。`src/features/account/access.ts` 将准入归纳为未登录、未认证、处理中、通过、失效与读取失败六种状态；未具备有效校园资格时内容页不挂载且不发业务请求，个人中心自有记录仍可访问。

## 账号与认证

头像菜单直接退出当前设备，点击后立即反馈进度。个人中心提供当前设备和全部设备两种退出范围，账号与安全页也提供退出全部设备。确认后撤销相应范围的 StuHelper 会话，回到门户并提示退出范围。Casdoor 注销未获确认时，门户另行提示。

账号与安全页实时读取本人的手机号绑定。可识别的大陆手机号保留前三位和后四位，中间四位用星号遮盖。无法识别的已绑定号码显示为 `****`。绑定或换绑需向新号码发送短信并提交六位验证码，页面在发码后显示重发倒计时。

绑定、换绑或解绑时，若服务端要求近期认证，页面跳转到认证入口并在返回后重新打开原操作。解绑需要确认，并展示服务端给出的拒绝原因，例如短信多因素认证仍开启或缺少其他登录方式。

登录提示提供 QQ 登录。账号与安全页按部署能力提供 OneBot、官方机器人和 QQ 互联三项绑定与解绑。QQ 互联授权返回 `/me/qq/callback` 确认。仅有旧 QQ 登录、尚未补齐 UnionID 的账号也可尝试解绑，服务端保护最后一种可用登录方式。

账号与安全页的实名区域显示状态。实名详情页读取凭据中的证件类型、脱敏姓名与脱敏证件号。当前契约识别 `cn_resident_id_card`，界面显示「居民身份证」。实名与学生资格分别展示。

实名信息校验等在线核对发出请求后显示等待提示。服务端以 HTTP `429` 和 `Retry-After` 指示冷却时，表单显示倒计时，并在结束前停用相应提交。提交失败在按钮附近播报并保留有效输入，加载失败在页面单独提供重试。

实名和邮箱校验收到无记录结果时，界面提示更换认证方式。收到信息不匹配结果时，界面提示核对所填信息后重试或更换认证方式。

学校资料卡展示学号、姓名和学院，认证时间取所选凭证的 `verified_at`。学生资格只使用学生申请判断是否正在审核。恢复教师认证表单时按需查询本人后续记录，成功读取表单与学校要求的材料后才允许编辑。邮箱认证按回执状态提示进度。

## 代码结构与传输层

```text
src/app/          路由、国际化、外壳布局与功能开关
src/shared/       同源传输、运行时契约校验、会话、幂等写入与通用组件
src/features/     按业务模块划分的页面、接口封装与单测
src/api/          提供方生成的 OpenAPI 类型与浏览器 SDK（禁止手改）
src/demo/         仅 VITE_DEMO=1 加载的审阅原型与模拟服务
src/locales/      八种语言界面词条
```

`src/shared/api/http.ts` 统一负责同源请求、CSRF 头注入、`redirect: 'error'`、超时取消、响应体积上限与错误码归一。接口封装使用 `schemaOf` 等解析器，按提供方契约校验 JSON 响应。

列表请求收到 HTTP 401 或 403 时清除私有记录和分页游标。账务冲突和余额不足继续使用业务错误码展示原因。

使用 `useMutation` 的幂等写入携带 `Idempotency-Key`。遇到结果不明的网络或网关故障时，表单进入 `uncertain` 状态，重试复用原请求体和幂等键。对于已收到 2xx 但无法解析或校验的写回执，页面引导刷新核对，阻止再次发送原写入。

会员购买等待回执期间锁定套餐与付款账户。仅在订单状态为 succeeded 或 fulfilled 时提示已开通，其他状态显示订单进度，可在钱包查看。

申请充值退款时可填写收款方式、收款人及账户。在允许更新的本人退款单中，可查看是否已登记并替换收款资料，页面使用脱敏回执。

个人资料发生版本冲突时，重新读取服务端版本，只恢复本人实际改动的字段。账号注销与 QQ 绑定操作在结果未决时复用原请求标识，解锁等待结束后可刷新交付结果。

存储贡献和账号托管使用提供方维护的浏览器 SDK。贡献操作先在对话框中确认，结果不明时只能重试原请求。切换到贡献标签或提交托管后立即清空未提交凭据，结果不明时只按申请标识查询。服务端确认查无申请后可重新填写，查询暂时失败时保留原标识。

会话检查合并并发请求，遇到 `503`、网络故障或超时按 1 至 8 秒有界退避，保留已挂载页面的用户输入。会话失效或账号更换时清除最近浏览、收藏缓存、对比项、未读数、资料目录和暂存筛选。

开放平台授权回调须使用已确认的 HTTPS 地址，保留注册的路径和查询参数。QQ 授权、支付跳转和资料协议链接只接受不含用户凭据的 HTTPS 地址。二维码支付指令仅以图像展示。

## 业务规则与状态说明

首次保存资料信息后，编辑器接续同一份草稿。再次进入上传页会新建独立草稿。文件上传并关联后才能提交审核。文件写入结果不明时先查询上传会话，取消只在服务端确认后显示完成。文件校验中只查询状态，就绪后关联。文件过期或被拒后可重选，复用文件的新资料仍单独审核。目录打包只包含有权访问的资料，列出全部分包并支持单包重试。

登录用户可从个人中心按资料编号发起侵权投诉。即使当前无法读取详情，投诉受理后仍可查看本人回执。分类浏览被拒时，编辑器使用本人资料版本内的分类快照并保留原课程关联。本人资料编辑与每次下载均由服务端授权，下载区分别说明缺少和暂时无法核实的条件。

资料标签可通过回车、逗号或离开输入框添加，支持逐个删除。最多添加 20 个标签，每个最多 64 个 Unicode 码点。重复标签按不区分大小写的方式去重，超过长度或数量上限的输入留待修改。投诉证据最多四项，每项最多 2000 个字符。空白数值保持缺失，空文件无法上传。

目录列表、分面计数与排序读取 `GET /api/v1/catalog/directory`，开课截止学期（默认 2023 秋）和可见性由服务端执行。推荐等级、五维分布与学期趋势读取 `GET /api/v1/reviews/summaries`，不展示精确数值均分。

对比表对每个对象独立显示统计结果。对象失效时保留其移除按钮和其他可读列。更改收藏夹失败后保留输入，移动收藏或删除文件夹后更新收藏状态。

课程分类条可横向滚动，点击课程性质标签可按性质筛选。筛选条件保存在浏览器历史条目中，刷新或前进后退可恢复。列表进入详情前保留页面状态，返回时恢复当前结果、筛选和滚动位置。启用搜索时首页可进入综合搜索与热门排行。搜索关闭时首页搜索转到课程目录。

课程目录的「按学院」视图采用响应式瀑布流，学院卡片以彩色边框区分，标题单行显示。卡片按折叠高度分列，展开只移动同列下方卡片。各学院独立预览和加载，可全部展开或收起。批量展开后按视口加载，各学院完整列表请求最多两项并发。

学校评分词表按会话和学校缓存 5 分钟，上限 32 项。个人中心复用准入服务的认证摘要。资料选择器打开后读取候选项，会员范围查询最多四项并发，按需继续读取目录。

评价列表携带 `include_reply_preview=true` 直接渲染回复数与前三条回复预览，旧服务端未返回预览时回退到进入视口后按需读取。通知列表携带 `include_content_names=true` 显示目标当前名称，内容删除或无权查看时显示不可用状态。

切换互动通知时，开关显示本次选择并暂时禁用。保存成功后显示服务端返回的设置，失败则恢复原值。已读数在服务端确认后更新。各分类未读数在还有分页时显示已知下限，系统通知可以继续加载历史记录。

选课记录与学期趋势按 `term_order_key` 排序，保留服务端夏季学期顺序。评价编辑器校验必选条件，支持普通草稿跨端冲突比对与撤回后 24 小时限时重编；撤回和删除按钮读取服务端的编辑权限。倒计时结束后重新查询本人评价，服务端确认窗口结束后显示审核申请入口。

评价编辑器区分自动填充与手动修改。丢弃回复后清空输入，教师公开身份回复需要本人确认。切换对象时清理旧统计和分包状态。

个人中心从本人接口读取评价、草稿及处置回执。准入过期后可继续编辑草稿正文，保留已有学期；目录名称只解析服务端列出的本人记录引用。“我的投票”（`/me/votes`）列出本人全部投票回执，可定位原帖或回复并撤销单票。搜索页按当前阅读权限展示投过票的内容。

“我的评价”的申请回执支持为待审复核补充证据。存储贡献页面可重新启用已退出的原记录，用户需重新勾选当前条款并确认贡献条件。

热门课程与教师按首页的排名继续翻页，每次翻页会重新检查可读范围。上次翻页超过 24 小时后，页面提示刷新，已加载的榜单保留到读者主动刷新。

存储透明度区分别展示申报、可用和已用容量。新增贡献时，云盘账号候选项显示当前可用容量。本人贡献记录展示申报上限和个人保留空间，有观测结果时同时展示已用、预留和可用容量。容量采用十进制单位呈现，表单按字节精确回填。

贡献记录使用可选备注名和脱敏账号区分记录。云盘托管账号页展示脱敏账号、状态和授权有效期，脱敏结果相同时附加记录标识末尾用于区分。

## 部署模块能力

应用启动时读取 `/api/v1/system/capabilities` 控制可选模块入口显隐。能力尚未返回前不挂载受控业务页；模块关闭时直接访问对应路径展示 404 且不发业务请求；能力接口读取失败时保留入口并交由服务端逐次授权。

收藏按钮与本人投票页分别受收藏和搜索能力控制。能力关闭时，相应组件和页面停止发起业务读取。

## 国际化

界面提供简体中文、英语、法语、俄语、日语、韩语、西班牙语和阿拉伯语。从 URL 的有效 `?lang=`、浏览器中保存的语言、默认中文依次选取。切换语言时加载消息、保存偏好，并更新页面的 `lang` 和 `dir`。阿拉伯语采用从右向左布局，脱敏标识使用独立文本方向。

新增界面文案提供八种语言的翻译键，包含可访问名称和错误提示。公共格式化接口按语言处理数字、金额、字节和时间，默认时区为 `Asia/Shanghai`。复数按原始数值选择，单测覆盖 I18N-02 的阿拉伯语六类复数和 I18N-03 的俄语四类复数。见[复数用例](src/app/plurals.test.ts)。

`pnpm run check:i18n` 检查键集合、空消息、占位符、复数类别和同英文文本。合法同形词在 `locale-policy.yaml` 按词条登记并写明原因，应用读取对应的 JSON 快照。ESLint 核验消息语法、重复键和硬编码文案。翻译用语和操作体验需要人工审阅。

## 契约与检查

`contracts/` 下的 OpenAPI 快照与 `src/api/*.gen.ts` 由提供方仓库生成并通过 `*.source.json` 记录版本、提交与 SHA-256 摘要，接口变更须先更新提供方契约再同步生成产物。

`make check` 执行会话、存储、贡献、认证、资料和学术契约检查，以及仓库检查、国际化、类型检查、ESLint、Vitest、生产构建和 `actionlint`。文档格式、链接与单段字数使用 `pnpm run check:docs` 单独检查。

本地安装依赖和 Chromium 后，使用以下命令验证正式构建和审阅原型。正式用例使用 HTTP 契约夹具，配置覆盖八种语言和桌面、移动两类视口。部分纯状态回归套件只运行中文、英语和阿拉伯语。

```bash
pnpm exec playwright install chromium
make build
pnpm run browser
pnpm run browser:demo
```

GitHub 的 `Web checks` 工作流执行仓库检查。触发浏览器任务时，还执行隔离 Nginx 转发测试、Chromium 用例和中文、阿拉伯语桌面下的传统滚动条布局用例。见[工作流配置](.github/workflows/checks.yml)。

`module.json` 的 `scenario_tests` 将规格编号关联到测试文件和用例标题。已登记场景包括校园准入、认证界面、目录浏览、资料流程、存储贡献和 QQ 绑定。见[模块清单](module.json)。
